Aconsegueix `elteunom.does.software` gratis i apunta'l al teu portfoli, el teu GitHub o el teu CV. El correu que arribi a `contacte@elteunom.does.software` et va a parar a la bústia que ja fas servir. No has de comprar cap domini, tocar els DNS ni posar targeta.

[Aconsegueix el teu subdomini gratis](https://does.software/ca/request/?ref=github)

## Què és does.software

[does.software](https://does.software/ca/?ref=github) dona subdominis gratuïts sota `does.software` i els serveix per tu. Tries una paraula, i aquest nom pot:

- Redirigir qui l'obri a qualsevol URL (el teu web, GitHub, LinkedIn, una pàgina de Notion…) per HTTPS, sense certificats per gestionar.
- Reenviar el correu que arribi a `algo@elteunom.does.software` al teu Gmail, al teu Outlook o a qualsevol altra bústia.
- Fer les dues coses alhora. La redirecció i el reenviament viuen al mateix nom, i pots canviar qualsevol de les dues quan vulguis.
- Enviar rutes concretes al seu propi destí, perquè `elteunom.does.software/cv` obri el teu CV i `elteunom.does.software/blog` el teu blog.

Cada nom compta a més els seus clics i els correus reenviats, sense galetes ni perfils de visitants.

## Com aconseguir un subdomini gratis

1. Entra a [does.software/ca/request](https://does.software/ca/request/?ref=github) i escriu la paraula que vols. El formulari et diu mentre escrius si està lliure.
2. Reclama-la. Amb compte, el nom s'activa en el moment que envies el formulari; sense compte, tan bon punt confirmes el teu email. També pots entrar amb Google, GitHub o GitLab.
3. Digues-li on ha d'anar, al mateix formulari o després des del teu panell:
   - Redirigeix els visitants a: la URL que ha d'obrir `elteunom.does.software`.
   - Reenvia el correu a: la bústia que rebrà el que s'enviï al teu nom. Aquesta bústia rep abans un email de confirmació, i el reenviament arrenca quan l'acceptes.

   Omple almenys un dels dos camps, o tots dos.
4. Obre `https://elteunom.does.software` i comprova que et porta on vas dir.

Els noms sensibles (marques grans, paraules com `login` o `billing`, termes institucionals) passen abans per una revisió manual breu, que sol resoldre's en menys d'un dia. Si el nom que vols ja està agafat, et pots apuntar a la seva llista d'espera i t'avisarem per email si es fa lliure.

## Pla gratis

| | Gratis |
|---|---|
| Subdominis | 1 |
| Redirecció web | Sí, després d'un avís de does.software de 3,5 s |
| Reenviaments de correu | 1 |
| Redireccions per ruta | 2 |
| HTTPS | Sí |
| Preu | 0 €, sense targeta |
| Renovació | Gratis, amb un clic cada 45 dies |

Renoves el nom amb un clic cada 45 dies. T'avisem 7 dies i 1 dia abans, i si se te'n passa, el nom continua reservat per a tu 3 dies més.

Els plans de pagament comencen a 2,56 €/mes. Amb ells el nom no caduca mai, la redirecció va sense avís i tens més reenviaments, una bústia de correu real des de la qual enviar i un web estàtic allotjat al teu nom. Mira la [taula de preus](https://does.software/ca/?ref=github#pricing) i les [preguntes freqüents](https://does.software/ca/faq/?ref=github).

## Per a què es fa servir

- `elteunom.does.software` apuntant al teu portfoli de programador o al teu perfil de GitHub
- `elteunom.does.software/cv` obrint el PDF del teu currículum
- `contacte@elteunom.does.software` al teu CV i a les teves candidatures, reenviat al teu correu personal
- Un enllaç curt per a un projecte de classe, un esdeveniment o un QR imprès que pots reapuntar més endavant

## Preguntes

### És gratis de debò?

Sí. El pla gratis no demana targeta ni té data de fi: un nom, 1 reenviament de correu i 2 redireccions per ruta, que renoves amb un clic cada 45 dies.

### He de configurar DNS?

No. does.software serveix la redirecció, el reenviament i el certificat HTTPS. Omples un formulari i el nom funciona.

### És el mateix que is-a.dev o is-a.software?

No, són projectes diferents amb noms semblants. Amb does.software configures una redirecció i correu sense tocar els DNS. is-a.dev i is-a.software et donen registres DNS per apuntar-los al teu propi allotjament. [Comparativa](https://does.software/ca/guides/does-software-vs-is-a/?ref=github).

### El puc fer servir amb GitHub Pages?

Pots apuntar la redirecció a la teva pàgina de `github.io` en qualsevol pla. Allotjar el web al mateix nom, també publicant-lo des d'un repo de GitHub o GitLab, ve amb la prova i amb els plans de pagament. [Guia](https://does.software/ca/guides/publish-from-github/?ref=github).

### Serveix com a alternativa a Freenom?

Si feies servir un domini gratis de Freenom per a una redirecció o una adreça de correu, sí. [Alternatives per tenir un domini gratis](https://does.software/ca/guides/freenom-alternatives/?ref=github).
